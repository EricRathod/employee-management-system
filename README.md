# Employee Management System
Python | SQLite | Pandas | CRUD Operations
## Overview
The Employee Management System is a Python and SQLite-based application developed to manage employee records efficiently. The system supports CRUD operations (Create, Read, Update, Delete) and SQL-based reporting.
## Features
* Add Employee
* View Employees
* Search Employees
* Update Employee Information
* Delete Employee Records
* Department-wise Employee Reports
* Salary Analysis
## Technologies Used
* Python
* SQLite
* Pandas
* Google Colab
* GitHub
## Database Design
Employee Table:
* Employee ID
* Full Name
* Department
* Job Title
* Email
* Phone Number
* Salary
* Joining Date
